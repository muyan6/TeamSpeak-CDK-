域名与 DNS 自动化绑定配置

配置域名解析服务商 API（支持 Cloudflare、阿里云、腾讯云），开通服务器时自动绑定专属二级域名 (SRV 记录)，免输端口直连并隐藏 IP。

💡 为什么无需泛解析？
系统在用户输入 CDK 兑换时自选二级域名前缀（如 play），后台通过 DNS API 只添加精准的 SRV 解析记录（_ts3._udp.play.yourdomain.com）。多台服务器可共用同一个主域名，互不影响；销毁服务器时自动回收记录。
