使用帮助与基础教程指南

开通专属 TS 语音服务器

输入 TS- 开头的卡密点击开通，系统会自动在服务器后台通过独立 Docker 容器秒级部署，并分配独立的专属语音与查询端口。

连接客户端与获取服主权限

打开 TeamSpeak 客户端，在地址栏输入 IP:端口 连接。首次进入会弹出权限秘钥窗口，粘贴页面给出的 Token 秘钥 即可成为超级管理员。

音乐机器人接入与网页点歌

使用 BOT- 开头的卡密开通。填入 TS 服务器 IP，语音端口推荐官方默认 9987（自建服务器填 60001 等），开通后点击控制台可在线点歌与播歌。

到期保护与快捷续费

机器人到期后自动停机断开，绝不会删除您的任何歌单与配置。随时在控制面板输入新 CDK 即可秒级延期并重新上线。

温馨提示与常见问题
  • 如果不慎关闭或刷新网页，只需在首页再次输入相同的 CDK 即可随时找回连接地址、Token 密钥与机器人控制面板。
  • 手机端用户（iOS / Android）下载 TeamSpeak App 后，点击右上角新建连接，填入相同的 IP:端口 即可随时上麦交流。
