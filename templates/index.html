使用帮助与基础教程指南

1
开通专属 TS 语音服务器

输入 TS- 开头的卡密开通，系统会自动在后台通过独立 Docker 容器秒级部署，分配专属语音与管理端口。

2
连接客户端与获取服主权限

打开 TeamSpeak 客户端输入 IP:端口 连接。首次进入粘贴给出的 Token 秘钥 即可成为超级管理员。

3
音乐机器人接入与网页点歌

输入 BOT- 开头卡密开通，填入 TS 地址与端口（商家服请参考下方提取）。开通后点击控制台可在线点歌与播歌。

4
到期保护与快捷续费

服务器与机器人到期后自动停机保护，绝不删除您的任何频道与配置。随时输入新 CDK 即可秒级延期恢复上线。

商家购买必看
第三方商家购买 TS 服务器真实端口查询指南

若您的 TeamSpeak 服务器是在第三方商家购买的，商家通常采用端口转发或 SRV / TSDNS 域名解析，实际语音端口大概率不是官方默认的 9987。若机器人填写错误的默认端口将无法连入您的语音频道。

4 步轻松提取真实端口：
1. 连入 TS 软件，点击顶部菜单栏 「工具 (Tools)」 ➔ 「客户端日志 (Client Log)」（快捷键 Ctrl+L）；
2. 顶部筛选 只勾选「信息 (Info)」（取消勾选警告与错误）；
3. 按 Ctrl + A 全选并复制全部日志文本。
无需手动计算，系统将秒级解析出真实连接 IP 与实际端口
温馨提示与常见问题
  • 如果不慎关闭或刷新网页，只需在首页再次输入相同的 CDK 即可随时找回连接地址、Token 密钥与机器人控制面板。
  • 手机端用户（iOS / Android）下载 TeamSpeak App 后，点击右上角新建连接，填入相同的 IP:端口 即可随时上麦交流。

如何获取客户端日志（只需 30 秒）：
① 打开电脑上的 TeamSpeak 客户端并连接进入您的服务器；
② 点击顶部菜单栏 「工具 (Tools)」 ➔ 「客户端日志 (Client Log)」（或快捷键 Ctrl + L）；
③ 在弹出的日志窗口顶部，只勾选「信息 (Info)」；
④ 点击日志区域按 Ctrl + A 全选并复制，粘贴到下方输入框中点击解析。
